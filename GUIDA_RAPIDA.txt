INSTAGRAM NEWS BOT — VERSIONE 3 — CAROSELLI
==================================

3 categorie: NOTIZIE BUONE (verde), NOTIZIE CATTIVE (rosso),
CURIOSITÀ (celeste). Tutte con fotografia e box testuale scuro.

IMPORTAZIONE
1. Estrai completamente lo ZIP sul computer.
2. Doppio clic su IMPORTA_SU_GITHUB.bat.
3. Incolla URL del repository GitHub esistente:
   https://github.com/TUO_UTENTE/instagram-news-bot
4. Serve Git for Windows: https://git-scm.com/downloads/win
5. Apri GitHub > repository > Actions.
6. Controlla che il workflow Controlli automatici finisca verde.
7. L'artifact preview-instagram contiene nove PNG demo: tre caroselli da tre slide.
8. Avvia Verifica Buffer (solo lettura) > Run workflow.
9. Avvia Instagram - esecuzione MANUALE:
   kind=demo, publish=false.
10. Apri il sito GitHub Pages per visualizzare i 3 caroselli da 3 immagini.

SICUREZZA
- NON attivare ALLOW_PUBLISH.
- Il calendario automatico è DISATTIVATO.
- Nessuna foto demo o notizia viene pubblicata su Instagram.
- La demo NON usa DeepSeek e NON consuma il tuo credito.
- Secrets già esistenti su GitHub: DEEPSEEK_API_KEY, BUFFER_API_KEY.
- Le demo contengono fotografie sintetiche di pura simulazione.

DOPO LA DEMO
Prima di pubblicare, fare un test reale con kind=positive e
publish=false. Richiede credito DeepSeek e accesso a Wikimedia.
Non usare foto editoriali senza licenza: il bot cerca fotografie
illustrative con licenza appropriata, non immagini del singolo evento.

In caso di problemi, invia il log Actions escludendo eventuali segreti.
